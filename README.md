# Автотесты для онлайн-калькулятора (Selenium + Pytest)

Проект содержит автотесты для проверки работы калькулятора процентов на сайте https://www.calculator.net. Реализован с использованием паттерна Page Object.

## Покрытые сценарии
* **Корректный расчёт:** проверка базовых математических вычислений с 5 наборами данных (через параметризацию).
* **Граничные значения:** ввод отрицательных чисел и нулей.
* **Неверный ввод:** проверка появления сообщения об ошибке при попытке ввести буквы вместо чисел.
* **Поведение кнопки «Clear»:** проверка очистки поля после нажатия кнопки сброса.
